ScamProof is an educational project for the ML Empowerment Build Challenge 3.0. It is a learning tool, not a security product — never rely on any single tool to judge a message.

Dataset: UCI SMS Spam Collection (Almeida, Hidalgo & Yamakami, 2011), CC BY 4.0 · Everything runs locally in your browser: no accounts, no cloud, no tracking.
